The server runs while its window is open. Closing the black server window stops training on every PC. If the server stops on its own, the window starts it again after 10 seconds.

1. Start the server

  1. Double-click scripts\start-occ-host.cmd in the project folder.
  2. Wait for the window to show: 
    OCC training server listening on http://0.0.0.0:8787/
  Open on the other PCs: http://<host-ip>:8787/
  3. Check on the host: open http://localhost:8787/api/health → shows "status": "ok".
  4. Leave the window open (minimise it if you like).

2. Before each class

  1. Server window is open (step 1).
  2. Trainer PC: open http://<host>:8787/ and sign in.
  3. Each trainee PC: open the same address, sign in, click Open my monitors.
  4. Drag the windows: Alarms → Monitor 01, Line Map → 02, Timetable → 03. Press F11 on each.
  5. Keep the Line Map window visible; it runs that exercise's trains.

3. Stop the server

  • After training, close the server window.
  • To start it automatically at sign-in: Win + R → shell:startup → add a shortcut to scripts\start-occ-host.cmd.
  • Only one server at a time: "Port 8787 is already in use" means one is already running.

4. Backups

  • Automatic every day to server\data\backups (newest 14 kept).
  • Back up now: People page → Back up now, or npm.cmd run backup.
  • Weekly: copy server\data\backups to the USB drive / network share above.
  • Restore: close the server, run npm.cmd run restore to list backups, then npm.cmd run restore -- <file>, start the server.

5. If something goes wrong

ProblemDo this
Other PCs cannot open the pageServer window open? On that PC open http://<host>:8787/api/health. Check the firewall rule for port 8787 and that the host's network is Private, not Public.
"Port 8787 is already in use"A server is already running (another window or the startup shortcut). Close the extra window.
Only one monitor window openedAllow pop-ups for the host address (address bar → pop-up icon → Always allow), then Open my monitors again.
Monitor says "View only"Another Line Map window is open for that exercise. Close it, or click Take control on the trainee's Line Map.
Trains move in jumps or stopThe Line Map window is minimised or hidden. Keep it on screen.
"The app is not built"In the project folder run npm.cmd run host:build, then start the server again.
Admin password lost or account lockedOn the host: npm.cmd run reset:password -- <username> <new password>
